# Ask, Don't Assume

## Rules
- If a request, requirement, or detail is unclear or ambiguous, ask the user before proceeding.
- Never guess missing information such as names, paths, versions, behavior, or scope.
- Do not fill gaps with your own assumptions; if you must proceed on a point, state it and get confirmation first.
- Prefer investigating the codebase for facts you can verify, and ask only about what cannot be determined that way.
- Ask concise, specific questions, offering concrete options when possible.
- If multiple interpretations exist, list them and let the user choose.
