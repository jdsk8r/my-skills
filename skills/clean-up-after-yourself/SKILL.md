# Clean Up After Yourself

## Rules
- If code you wrote does not work, remove it before moving on.
- If a temporary solution was replaced by a better one, delete the temporary one.
- Remove unused variables, functions, parameters, and imports.
- Delete temporary files, debug output, and commented-out code you created.
- Before finishing, review the full diff for leftovers.
