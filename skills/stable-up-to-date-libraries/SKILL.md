# Stable, Up-to-Date Libraries

## Rules
- Only suggest libraries that are stable and under continuous development.
- Do not consider outdated, deprecated, or abandoned libraries.
- Check recent releases and maintenance activity before recommending.
- Always use the latest stable version; verify it from the registry (Maven Central, npm, PyPI, etc.) rather than relying on memory.
- Do not use pre-release versions unless the user asks.
