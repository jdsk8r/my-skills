# my-skills

Personal agent skills. Each skill lives in `skills/<name>/SKILL.md` (name matches the folder).

## Using with agents
Link or copy `skills/*` into the agent's skills directory:
- opencode: `.opencode/skills/` or `~/.config/opencode/skills/`
- Claude Code: `.claude/skills/` or `~/.claude/skills/`
- Codex and others: `.agents/skills/` or `~/.agents/skills/`
